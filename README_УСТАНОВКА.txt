МОЙ РАЦИОН — ПРИЛОЖЕНИЕ ДЛЯ IPHONE
Версия 1.0 (14 октября 2026 г.)

ЧТО УМЕЕТ
• Рассчитывает норму калорий, белков, жиров и углеводов по полу, возрасту,
  весу, росту, уровню активности и цели (снижение/поддержание/набор веса).
• Позволяет вручную задать нормы калорий, белков и жиров.
• Составляет меню на день из завтрака, обеда, ужина и перекуса,
  подбирает рецепты и массу порций с учётом всей дневной нормы БЖУ.
• Меняет блюдо, генерирует другое меню, отмечает съеденные блюда.
• Ведёт дневник питания с учётом веса продукта в граммах и историей за 7 дней.
• Содержит базу из 60+ продуктов и позволяет добавлять свои продукты.
• Хранит данные только на устройстве; экспортирует и импортирует резервные копии JSON.
• После установки работает без интернета.

КАК УСТАНОВИТЬ НА IPHONE В КАЧЕСТВЕ ПРИЛОЖЕНИЯ
Потребуется один раз выложить файлы из этого архива на веб-хостинг по HTTPS:

1. Распакуйте ZIP на компьютере. Сохраняйте файлы и папку icons вместе.
2. Разместите содержимое распакованной папки на статическом HTTPS-хостинге.
   Подойдут GitHub Pages, Netlify, Cloudflare Pages или ваш сервер с HTTPS.
   В корне опубликованной папки должен лежать index.html.
3. Откройте получившийся HTTPS-адрес на iPhone именно в Safari.
4. Нажмите «Поделиться» (квадрат со стрелкой вверх).
5. Найдите «На экран «Домой»» / «Добавить на экран Домой» и нажмите «Добавить».
6. Откройте значок «Мой рацион» на домашнем экране.
7. Во вкладке «Профиль» укажите свои данные, а затем откройте вкладку «Меню».

После первого успешного запуска по HTTPS основные файлы приложения
сохраняются для работы без интернета. Установка не требует App Store.

ВАЖНО
• ZIP — это исходные файлы веб-приложения (PWA), а не подписанный iOS-файл IPA.
  Для прямой установки через App Store нужен отдельный процесс сборки/публикации.
• Отдельный файл «Мой_рацион_просмотр.html» в комплект не входит:
  он предоставлен рядом как удобный ознакомительный вариант для браузера.
  При открытии HTML непосредственно из «Файлы» на iPhone сохранение данных
  может быть ограничено; для регулярного использования рекомендован HTTPS-вариант.
• Все данные (включая личные параметры и журнал) находятся только в браузере
  конкретного устройства и могут исчезнуть при удалении данных сайта.
  Периодически используйте «Профиль» → «Экспорт», сохраните JSON в «Файлы».
• Указанные нормы и пищевые данные приблизительны, для взрослых 18+,
  не учитывают беременность, заболевания и медицинские противопоказания.
• Значения у продуктов указаны на 100 г, если в названии не сказано иное.
  Калорийность приготовленного блюда зависит от продуктов и метода готовки.
